# API Demo – Zignuts Technology

A .NET  Web API built as part of the assignment

## Features
- CRUD operations for Student Details
- validation / error handling

## Tech Stack
- C#, .NET

## Getting Started
1. Clone the repo
   `git clone https://github.com/Devyani1907/APIDemo-ZignutsTechnology.git`
2. Open the solution in Visual Studio
3. Update the connection string in `appsettings.json` (if applicable)
4. Run the project (`F5`) or `dotnet run`

## API Endpoints
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET    | /api/StudentAPI/GetStudentDetailInReverse | Get student information in reverse string. |
